# What is Science?

This repository contains my very first website, originally built during high school using XHTML 1.0 Transitional DTD. The website explores various scientific topics including biology, chemistry, physics, and space, alongside profiles of famous scientists and technological innovations.

In addition to the raw website files, this repository preserves the complete planning, design, and evaluation documentation required for the school project assessment.
